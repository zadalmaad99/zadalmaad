# مجلد ملفات PDF

ارفع هنا ملفات PDF الخاصة بكتب المنهج (عبر واجهة GitHub على الموقع — زر "Add file" ثم "Upload files" — بدون الحاجة لأي أوامر).

بعد رفع أي ملف، رابطه الجاهز للاستخدام في إعدادات التطبيق هو:

```
https://cdn.jsdelivr.net/gh/zadalmaad99/zadalmaad@master/pdfs/اسم_الملف.pdf
```

استبدل `اسم_الملف.pdf` باسم الملف الذي رفعته بالضبط (احرص أن يكون الاسم بحروف/أرقام إنجليزية أو بدون مسافات لتفادي مشاكل الترميز في الرابط).

**ملاحظة:** بعد الرفع، قد يستغرق جلب jsDelivr للنسخة الأولى من الملف بضع دقائق (يخزّنه على شبكة توزيع عالمية CDN) — إذا لم يفتح فورًا، أعد المحاولة بعد دقيقتين.
